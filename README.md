# PC 관리 도구 v2

Everything 방식의 **초고속 파일 검색**을 메인 화면으로, 기존 PC 관리 기능을 두 번째 탭에 둔 Windows 도구입니다.

- 실행 파일 **약 100KB 단일 exe** (v1: .NET 6 self-contained 약 150MB)
- Windows 10/11에 기본 탑재된 .NET Framework 4.8 사용 → 별도 설치 불필요
- WMI 등 무거운 라이브러리 미사용 (Win32 API 직접 호출)

## 탭 1 — 파일 검색 (메인)

| 항목 | 내용 |
|---|---|
| 색인 방식 | 관리자 권한: NTFS MFT 직접 읽기(수 초) / 일반 권한: 병렬 폴더 탐색 |
| 시작 속도 | 색인을 `%LOCALAPPDATA%\PCManagerCS\index.dat`에 저장 → 다음 실행 시 즉시 검색 가능 |
| 실시간 반영 | 파일 생성·삭제·이름 변경을 감시하여 색인에 자동 반영 |
| 검색 속도 | 약 200만 개 항목 기준 10~150ms (입력할 때마다 즉시 검색) |

### 검색 문법

| 입력 | 의미 |
|---|---|
| `보고서 2025` | 이름에 두 단어가 모두 포함 (AND) |
| `"주간 보고"` | 공백 포함 구문 |
| `!temp` | 제외 |
| `*.hwp`, `보고서??.pdf` | 와일드카드 (이름 전체 일치) |
| `D:\자료\ 계약` | `\`가 들어간 단어는 전체 경로에서 검색 |
| `ext:pdf;docx` | 확장자 |
| `file:` / `folder:` | 파일만 / 폴더만 |

분류 드롭다운: 전체 · 폴더 · 파일 · 문서 · 이미지 · 오디오 · 비디오 · 압축 · 실행 파일

### 단축키

| 키 | 동작 |
|---|---|
| `Enter` / 더블클릭 | 열기 |
| `Ctrl+Enter` | 파일 위치 열기 (탐색기에서 선택) |
| `Ctrl+C` | 전체 경로 복사 |
| `Delete` / `Shift+Delete` | 휴지통으로 삭제 / 영구 삭제 |
| `F2` | 이름 바꾸기 |
| `Alt+Enter` | 속성 |
| 우클릭 / 메뉴 키 | 탐색기와 같은 Windows 우클릭 메뉴 |
| `↓` / `↑` | 검색창 ↔ 결과 목록 이동 |
| `Esc` | 검색어 지우기 |
| `Ctrl+F` | 검색창으로 |
| `Ctrl+1` / `Ctrl+2` | 탭 전환 |
| `F5` | 다시 색인 |

결과를 우클릭하면 탐색기와 같은 Windows 메뉴(열기, 연결 프로그램, 압축, 보내기, 잘라내기·복사, 삭제, 속성 등)가 나오며,
'열기' 아래에 **파일 위치 열기 · 전체 경로 복사 · 이름 복사 · 이름 바꾸기**가 추가되어 있습니다.
결과를 탐색기·메일 등으로 끌어다 놓을 수 있고, 열 머리글을 클릭하면 이름·경로·크기·날짜순으로 정렬됩니다.

## 탭 2 — PC 관리

| 구분 | 기능 | 비고 |
|---|---|---|
| 시스템 정리 | 시스템 복구 (DISM + SFC) | 일반 권한이면 관리자 콘솔 창에서 실행 |
| | 임시 파일 정리 | 확보 용량 표시, 사용 중 파일은 건너뜀 |
| | 브라우저 캐시 정리 | Chrome · Edge · 웨일 · Brave · Vivaldi · Opera · Firefox 중 설치된 브라우저 자동 감지. 캐시만 삭제 (로그인·기록·비밀번호 유지) |
| | Office 수정 | **Office(클릭투런)가 설치된 경우에만 표시**, 설치된 플랫폼(x86/x64)·언어 자동 감지 |
| 시스템 최적화 | 시작 프로그램 관리 | 레지스트리 Run · 시작 폴더 항목 켜기/끄기. 작업 관리자 '시작 앱'과 같은 방식이라 삭제하지 않고 되돌릴 수 있음 |
| | 디스크 검사 | 빠른 검사(/scan) 또는 검사 및 복구(/f /r) 선택 |
| 문제 해결 | 네트워크 초기화 | 빠른 초기화(IP 다시 받기) / 전체 초기화(Winsock · TCP/IP, 재부팅 필요). 고정 IP 사용 시 설정을 로그에 기록하고 경고 |
| | DNS 캐시 정리 | |
| | 프린터 대기열 초기화 | 스풀러 중지 → 대기 중인 인쇄 작업 삭제 → 스풀러 시작 |
| | 시간 동기화 | 인터넷 시간으로 동기화 후 오차 표시. 도메인 PC는 시간 서버 설정을 변경하지 않음 |
| 시스템 확인 | 시스템 정보 | OS·CPU·메모리·네트워크·디스크 |
| | IP 변경 | 어댑터 선택, 프로그램 재시작 없이 적용 (UAC 1회) |
| | 배터리 리포트 | 배터리가 있는 PC에서만 표시 |

관리자 권한이 필요한 기능은 일반 권한으로 실행 중이어도 해당 명령만 관리자 권한(UAC)으로 실행하고, 결과는 실행 로그에 표시합니다.

v1에 있던 **회사/학교 계정 정리**, **원드라이브 초기화** 기능은 제거되었습니다.

## 자동 업데이트

프로그램을 시작하면 GitHub Release(`grasion/pc-manager`)의 최신 버전을 확인합니다.
새 버전이 있으면 상단에 **새 버전** 버튼이 나타나고, 누르면 exe를 내려받아(크기·SHA-256 확인) 교체한 뒤 다시 시작합니다.
프로그램 폴더에 쓸 권한이 없으면 릴리스 페이지를 엽니다. 오프라인이거나 확인에 실패하면 아무것도 표시하지 않습니다.

## 배포 (GitHub Release 업로드)

`배포.bat`을 실행하고 새 버전을 입력하거나, PowerShell에서:

```powershell
.\release.ps1 2.0.1
.\release.ps1 2.0.1 -Notes "변경 내용"
```

버전 반영 → 빌드 → 커밋·태그 → GitHub 푸시 → Release에 `PCManagerCS.exe` 업로드까지 한 번에 진행합니다.
처음 실행할 때 저장소가 없으면 공개 저장소로 만듭니다. 필요: dotnet SDK, git, GitHub CLI 로그인(`gh auth login`).

## 빌드

```cmd
build.bat
```
또는 `dotnet build -c Release` → `bin\Release\net48\PCManagerCS.exe`

## 파일 구조

```
PCManagerCS/
├── Program.cs        진입점, 관리자 권한 확인/재시작, 오류 로그
├── MainForm.cs       메인 창 (헤더 + 탭)
├── SearchPage.cs     파일 검색 탭 (가상 목록, 정렬, 열기/복사/끌어놓기)
├── FileIndex.cs      색인 저장소, MFT 읽기, 폴더 탐색, 검색 엔진, 실시간 감시, 캐시
├── ManagePage.cs     PC 관리 탭 (기능 카드 + 실행 로그)
├── SystemTools.cs    Office 감지, 시스템 정보, 임시 파일 정리, 프로세스 실행
├── IPConfigForm.cs   IP 설정 창
├── StartupForm.cs    시작 프로그램 관리 창
├── BrowserCache.cs   브라우저 감지 · 캐시 정리
├── ShellMenu.cs      Windows 셸 우클릭 메뉴 (IContextMenu)
├── Coffee.cs         개발자에게 커피 사주기 버튼 · QR 창
├── Assets/coffee_qr.png  후원 QR 이미지 (exe에 포함)
├── Updater.cs        GitHub Release 업데이트 확인 · 자동 교체
├── Theme.cs          색상·글꼴·사용자 정의 컨트롤
├── Native.cs         Win32 API 선언
├── release.ps1       배포 스크립트 (빌드 → 커밋/태그/푸시 → Release 업로드)
├── 배포.bat          release.ps1 실행용 (버전 입력)
└── _backup_v1/       v1 원본 소스 백업 (git 제외)
```

오류가 발생하면 `%LOCALAPPDATA%\PCManagerCS\error.log`에 기록됩니다.
